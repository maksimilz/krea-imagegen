# Krea ImageGen (ComfyUI) for SillyTavern

**Krea ImageGen** — расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern), обеспечивающее однопроходную (1-Pass / In-Context) генерацию изображений через локальный [ComfyUI](https://github.com/comfyanonymous/ComfyUI).

---

## ✨ Основные возможности

- ⚡ **1-Pass Генерация (Single-Pass In-Context):** LLM генерирует текст истории и одновременно вставляет визуальные промпты в одном ответе. Никаких лишних повторных вызовов модели!
- 🎨 **Оптимизировано под Krea-2 / Flux / SDXL:** Специальные шаблоны кинематографичных, POV и портретных описаний.
- 📐 **Автоматический выбор соотношения сторон (Dynamic Aspect Ratio):** Автоматическое определение разрешения кадра (16:9, 21:9, 9:16, 3:4, 1:1) по контексту сцены или прямо в теге.
- 🔄 **Инлайн-свайпы и история вариантов:** Каждое сгенерированное изображение сохраняет историю вариантов прямо в сообщении — переключайтесь стрелками (`<` / `>`).
- ↻ **Мгновенная регенерация без LLM:** Кнопка повторной генерации (`↻`) на самом изображении в чате заново отправляет промпт напрямую в ComfyUI без траты токенов LLM.
- 🔍 **Встроенный Lightbox:** Просмотр изображений на весь экран с зумом и навигацией по истории вариантов.
- 🛡️ **Надежный парсер:** Игнорирует блоки рассуждений моделей (`<think>`, `<thought>`), распознает теги `<img prompt="...">`, `[IMAGE: ...]`, `[pic: ...]`.

---

## 📦 Установка

1. Перейдите в папку с расширениями SillyTavern:
   ```bash
   cd SillyTavern/public/scripts/extensions/third-party
   ```
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/maksimilz/krea-imagegen.git
   ```
3. Перезапустите SillyTavern или обновите страницу браузера (`Ctrl + F5`).
4. Откройте панель расширений SillyTavern (иконка кубика 🧩), найдите **Krea ImageGen (ComfyUI)** и включите его.

---

## ⚙️ Настройка ComfyUI

- Убедитесь, что ComfyUI запущен с флагом `--listen` или доступен по адресу `http://127.0.0.1:8188`.
- В настройках расширения в SillyTavern укажите адрес сервера ComfyUI и выберите желаемый воркфлоу или модель чекпоинта.
