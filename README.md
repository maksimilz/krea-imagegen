# Krea ImageGen (ComfyUI) for SillyTavern

**Krea ImageGen** — расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern): модель истории сама вставляет в ответ теги картинок `<img prompt="…" width="…" height="…">`, а расширение рендерит их в локальном [ComfyUI](https://github.com/comfyanonymous/ComfyUI). Без второго запроса к LLM (1-pass). Заточено под **Krea 2 Turbo** и модели на её основе (RedCraft и др.), есть шаблоны для **Anima** и **MOSS-Image**.

---

## ✨ Возможности

### Промпты
- **1-pass:** инструкция для картинок добавляется в запрос перед последним сообщением пользователя. Модель пишет историю как обычно (на своём языке) и вставляет теги после нужных абзацев. В конце запроса — короткое напоминание о количестве картинок.
- **Шаблоны:** Кино, POV, Портрет (проза для Krea 2), Anima и MOSS (голова Danbooru-тегов + предложения).
- **Правила, проверенные на Krea 2 Turbo:**
  - один абзац обычного английского, 80–160 слов;
  - кадр и объектив → свет (1–2 источника) → люди → обстановка;
  - без отрицаний: у Turbo нет рабочего негатива, и «no hat» рисует шляпу;
  - без quality-слов и весов;
  - у каждого человека в кадре есть возраст и пол;
  - явно сказано, что из одежды распахнуто, приспущено или ещё надето;
  - надписи в одинарных кавычках.
- **Постоянство внешности:** имена в промпт не попадают, каждого персонажа описывают полностью. Последние промпты чата передаются модели как образец формулировок, при этом история чата остаётся без картинок, и кэш провайдера не сбрасывается.
- **Откровенные сцены** описываются прямо. Галочка «Мягкие формулировки» включает сдержанный вариант для строгих API.
- **Количество:** 1–4 картинки за ответ или «сама» (по визуальным моментам), «особая картинка» по твоему заданию, режимы «каждый ответ / каждые N / когда делятся фото / только по кнопке».

### Стили
- **Одна галерея из двух библиотек:**
  - [Clio Style Library](https://github.com/lumenastrum/clio-style-preview) — 398 стилей, написанных под Krea 2;
  - [Style Atlas](https://github.com/atlasimp/Style_Atlas) — около 1500 стилей и модификаторы света, настроения, палитры.
  - Дубли по названию скрыты, при совпадении остаётся версия Clio. Есть фильтры по источнику, категории и «только с картинкой», избранное и недавние.
- **Свой стиль для каждого чата:** стиль и модификаторы запоминаются в чате и возвращаются, когда ты в него заходишь.
- **🤖 Подобрать под чат:** модель истории читает карточку и историю, учитывает твои пожелания и предлагает 6 стилей с пояснениями (один тихий запрос).
- Модель знает, какой стиль выбран, и пишет сцену под него. Сам текст стиля добавляется к промпту автоматически.

### Картинки в чате
- **Очередь:** ↻ во время рендера не отклоняется, а встаёт в очередь (можно нажать несколько раз). Ответы, пришедшие во время рендера, тоже ждут. «Пропустить» переходит к следующей задаче, «Стоп» очищает очередь.
- **Кнопки на картинке:**
  - ↻ новый вариант без LLM;
  - 🎨 вариант в другом стиле (стиль чата не меняется);
  - ✎ правка промпта;
  - копировать, скачать.
- Варианты переключаются стрелками, есть полноэкранный просмотр с зумом.
- **Упавший рендер** не теряет промпт: «Повторить», «Править», «Копировать». Есть автоповтор при сбоях ComfyUI.
- **Фоновые чаты:** если ты ушёл в другой чат, картинка всё равно запишется в нужный.

### Рендер
- **Профиль на каждый workflow:** LoRA (4 слота с триггер-словами), сэмплер, шаги, CFG. При смене workflow они подставляются сами.
- **Размер под кадр:** модель выбирает пропорции из списка Krea 2 (16:9, 4:3, 1:1, 3:4, 2:3, 9:16, 21:9). Странные размеры приводятся к ближайшему.
- **Повышенное разрешение:** ~1.5 Мп вместо ~1 Мп в тех же пропорциях. Заметно детальнее волосы, кожа и ткань, рендер на ~30% дольше.

## 📦 Установка

1. В папке расширений SillyTavern:
   ```bash
   cd SillyTavern/public/scripts/extensions/third-party
   git clone https://github.com/maksimilz/krea-imagegen.git
   ```
2. Перезапусти SillyTavern или обнови страницу (`Ctrl + F5`).
3. В панели расширений (🧩) открой **Krea ImageGen**, укажи адрес ComfyUI и нажми «Проверить».

Обновление: `git pull` в папке `krea-imagegen`, затем `Ctrl + F5`.

## ⚙️ ComfyUI

### Workflow
Workflow хранятся в SillyTavern (`data/<user>/user/workflows`, формат **API**). Расширение подставляет в них плейсхолдеры:

| Плейсхолдер | Что подставляется |
|---|---|
| `%prompt%` | промпт (обязателен) |
| `%negative_prompt%`, `%seed%`, `%steps%`, `%scale%`, `%sampler%`, `%denoise%` | из настроек |
| `%width%`, `%height%` | размер кадра |
| `%model%` | модель из настроек |
| `%lora1%`…`%lora4%`, `%lorawt1%`…`%lorawt4%` | LoRA-слоты; пустой слот убирается из графа |
| `%style%` / `%clio_style%` | имя стиля Clio для ноды ClioStyle |
| `%style_text%`, `%style_source%` | текст стиля Atlas и источник (`clio` / `atlas` / `none`) |

Под выбором workflow видно, какие плейсхолдеры он использует.

### Стили
- **Clio:** нода [clio-style-preview](https://github.com/lumenastrum/clio-style-preview) в `custom_nodes`. Если в workflow нет ноды ClioStyle, она добавляется автоматически. Превью берутся из её галереи.
- **Style Atlas:** нужен [Style_Atlas](https://github.com/atlasimp/Style_Atlas) и мост `megumin_style_atlas_bridge` (маршруты `/megumin/style_atlas…`). Без моста Style Atlas просто не показывается, работают стили Clio. Стиль Atlas и модификаторы пишутся прямо в текст промпта.

### Рекомендуемые настройки (тесты на RTX 5060 Ti, ноябрь 2026)
| Модель | Сэмплер | Шаги | CFG | Заметки |
|---|---|---|---|---|
| Krea 2 Turbo (официальная) | euler / simple | 8 | 1 | er_sde 10 не дал заметной разницы |
| RedCraft (Krea2) | er_sde / simple | 10 | 1 | точнее держит одежду и детали, ~17 с за кадр |

- Каждый новый промпт добавляет несколько секунд на кодирование текста (Qwen3-VL); повторный рендер того же промпта быстрее.
- Стилевые LoRA с триггер-словом (например Niji Sweet Spot `@NJSW33T`) ставь в слот и впиши триггер: он добавится в начало промпта. Текстовый стиль при этом лучше выключить, чтобы он не спорил с LoRA.
